# Danmaku Renderer PoC

This is a proof-of-concept for rendering scrolling comments (danmaku) onto a video file using ffmpeg.

The logic is implemented in C++ and generates a shell script to perform the final render.

## Prerequisites

- A C++17 compiler (like g++)
- `ffmpeg` installed and available in the system's PATH.

## How to Run

1.  **Compile the renderer:**
    ```bash
    g++ -std=c++17 parser.cpp -o renderer
    ```

2.  **Generate the render script:**
    The C++ program reads comment data from `comments.json`, calculates timings and layout, and prints a complete `ffmpeg` command to standard output.
    ```bash
    ./renderer > render.sh
    ```

3.  **Make the script executable:**
    ```bash
    chmod +x render.sh
    ```

4.  **Run the render script:**
    This will execute the `ffmpeg` command and create `final_output.mp4`. This process can take some time depending on the video length and number of comments.
    ```bash
    ./render.sh
    ```

## Files

- `parser.cpp`: The main C++ source file. It contains the logic for parsing comment data, calculating layouts, and generating the ffmpeg command.
- `comments.json`: The input data file containing the comments to be rendered.
- `json.hpp`: The "JSON for Modern C++" single-header library used for parsing `comments.json`.
- `render.sh`: The output shell script generated by the C++ program.
- `final_output.mp4`: The final video with the rendered comments.
